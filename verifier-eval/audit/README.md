# Audit coding rule

strong = the remaining text alone would make a careful reader say SUPPORTED or REFUTED;
weak = there is a hint but not enough to decide; none = nothing relevant.
topically_related = yes if the inserted sentence concerns the same disease, gene, intervention or
outcome as the claim. For C1 rows (several inserted sentences), topically_related = yes means that at
least one inserted sentence relates to the claim. Code independently, then compare.
